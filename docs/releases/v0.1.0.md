# WSM v0.1.0

Windows Subsystem for macOS: macOS Tahoe 26.3 (x86-64) in a VM on Windows 11, driven by one CLI.

## Download
- `wsm-setup.zip` (about 50 MB): `wsm.exe`, `wsmd.exe`, QEMU runtime with the six WHPX patches, reims-vgpu 7bdb4ec0, OpenCore AMD/Intel templates, `install.ps1`, sources and licences. Verify with `SHA256SUMS`.
- **No macOS content is included.** You build the base yourself from an installer you own:
  - light base (headless, suspend/resume, 1.0 GB, about 8 minutes): `wsm base build-lite --iso <Tahoe ISO>`
  - full base (GPU desktop, 17.9 GB, about 1-2 hours): `wsm base build --iso <Tahoe ISO>`

## Highlights
- Resume in about 2 s (core instances), warm `wsm exec` about 40-60 ms.
- Light base: `wsm exec --root`, `wsm run --detach` / `jobs` / `kill`, Homebrew working (hello from source 3 min, jq bottle 13 s).
- GPU profile: paravirtual GPU on Vulkan, desktop window via `wsm gui start`.
- Nothing is installed system-wide; `wsm uninstall --yes --portable` leaves Windows untouched.
